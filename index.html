Pixel Agent: Failure-Mode Analysis of Computer-Use Agents

Ongoing · Independent study, CMU

Computer-Use Agents · OSWorld · GUI Grounding · VLM-as-Judge

Studying why computer-use agents (CUAs) fail on real desktop tasks. Building a failure-mode taxonomy that separates perception/grounding errors from cognitive/planning errors, and a VLM-as-judge pipeline that classifies errors in OpenCUA agent trajectories on the OSWorld benchmark by comparing them against human (OSWorld-Human) trajectories, validated through manual annotation and inter-annotator agreement studies.

On the GUI-grounding side, reproduced and improved OpenCUA results, lifting ScreenSpot-V2 87.0 → 91.5 and OSWorld-G 46.5 → 48.8 at 32B, and built trajectory-visualization and annotation tooling to support the error analysis.

Selected Projects

Agent Harness for Coding and Game-Playing LLM Agents

A harness for running AI agents, built from scratch: a loop that lets a language model reason, call tools, run code in a sandbox, and keep working through a task over many steps. The same loop drives two very different agents, one that fixes bugs in real code repositories and one that plays chess.

I used it to answer a practical question: when an agent's history grows too long to fit, does summarizing the older parts actually save anything? It halved the largest prompt, but writing those summaries costs tokens too, and the details they dropped forced the agent to redo work, leaving a net saving of only 8%. A second experiment across two models found that which model you use matters far more than how much information you show the agent.

GoT-Diffuse: Compositional Text-to-Image Generation

Image generators that plan a layout before they draw still put objects in the wrong places. I built a diagnostic to find where that breaks down, and the answer was clear: the plans themselves were correct 83% of the time, but only 65% of finished images actually followed them. The failure is in the drawing, not the thinking.

Guiding the generator with an explicit layout recovered much of that gap, improving spatial relationships 19% and color assignment 15%, and pointing toward a decoder that holds on to each object's description through the early, most formative steps of generation.

TS-QFormer: Time-Series-to-LLM Adapter for QA

Sensor readings and language models do not naturally speak to each other. This project builds a small translator between them, so you can ask questions in plain language about numerical time-series data without retraining either the language model or the encoder that reads the signal.

The adapter learns which stretch of a long signal a given question is actually about, and was trained to reason step by step through time rather than jumping straight to an answer, which measurably improved answer quality over a direct-answer baseline.

Deep Learning Framework and Generative Models from Scratch

A deep learning library built from the ground up with no framework underneath it: automatic differentiation, optimizers, and a tensor engine with hand-written GPU kernels, including a memory optimization that cut attention memory by more than 20%.

On that foundation I built an image-generating diffusion model and a GPT-style language model with two modern attention improvements, which trained to 10% lower validation loss than the baseline.
